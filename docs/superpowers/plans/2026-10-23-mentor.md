# Mentor (Ozan) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An animated, voiced mentor "Ozan" narrates Home, Lab, Simulator and Training, reacts to what users write through an on-device embedding engine, and the app is restyled to match. Everything ships in one TestFlight build.

**Architecture:**
- Pure TypeScript rig math (springs, limits, geometry) drives a Skia character through Reanimated shared values.
- Lines live in typed EN/TR script files. A local Python pipeline pre-renders them to audio plus loudness envelopes, and the app plays them with expo-audio while the envelope drives the jaw.
- Reactions come from matching an on-device sentence embedding against a shipped prototype library, with a safe universal fallback.

**Tech Stack:** Expo SDK 58, RN 0.88, `@shopify/react-native-skia`, `react-native-reanimated` 4.7, `expo-audio`, `react-native-executorch` (fallback `onnxruntime-react-native`), `jest-expo`; Python 3.12 with `chatterbox-tts` (multilingual), `kokoro`, `sentence-transformers`, ffmpeg.

**Spec:** `docs/superpowers/specs/2026-10-23-mentor-design.md` (read it first; the art-direction and mood table are requirements).

## Global Constraints

- Free tools only; no network calls with user data; works offline after install.
- iOS only; perf target iPhone 11 at 60 fps; app size is not a concern.
- English is the source of truth; `tr` must match `en`'s shape (both i18n and mentor script).
- The mentor never speaks user-written text; voiced lines are fixed strings.
- Crisis: a phrase match blocks the flow (current behaviour). An embedding-only crisis match offers support with a "continue" option.
- Every rig parameter is clamped to `LIMITS`, and springs are integrated in substeps of ≤ 4 ms.
- The lash line is the upper lid's bottom edge, clipped to the eye.
- Sleeves are filled, tapered shapes (never stroked tubes). Hands are tucked in the sleeves at rest. The lantern stands on the ground. The body is slim with sloped shoulders.
- Install packages with `npx expo install`. Run `npx tsc --noEmit`, `npx expo lint` and `npx jest` before every commit.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. A clip fails to load, or the manifest has no entry: the line still shows its subtitle and the mouth moves procedurally, so the flow never hangs. Test in Task 6.
2. Empty, emoji-only, very long (2,000+ chars) or mixed-language user text gets a universal or valid reaction with no throw. Test in Task 7.
3. Tapping fast and spamming skip while a line plays never leaves overlapping audio, and the queue ends in a consistent state. Test in Task 6.
4. Switching language mid-session makes the next lines and audio use the new language, and a missing TR clip falls back to subtitle only. Test in Task 6.
5. Text that says "I had a terrible day" (no crisis) is not blocked. "I want to die" is blocked. Test in Task 7.

**Interfaces:**
- Produces:
  - `match(vec: Float32Array | null, text: string, lang: Lang, recent: string[]): { situation: string | null; lineId: string; mood: Mood; gesture: Gesture; crisis: 'block'|'offer'|null }`. Rules:
    - the phrase check gives `block`;
    - the best crisis prototype at cosine ≥ 0.55 gives `offer`;
    - otherwise a situation when best ≥ 0.62 and best − second ≥ 0.04;
    - keyword topic (`detectTopic`) breaks ties;
    - otherwise a universal line;
    - a line from `recent` (last 6) is never picked when an alternative exists;
    - `vec === null` (model not ready) uses keyword topic plus universal.
  - `useEmbedder(): { ready: boolean; embed(text: string): Promise<Float32Array | null> }`. The model is bundled as an asset. It returns null on any error, and the input is truncated to 512 tokens.
  - `react(text: string): Promise<ReturnType<typeof match>>` on `useMentor`, which also says the line.
