## Assessment

The risk is moderate and manageable. Neither user is a registered mark that we found. The writing-tools vendor is the one to watch, because "software that helps you plan and think" sits close to class 9/41 for both of us.

If a register shows a live mark in class 9 or 41, change the name before public release. A rename costs:
- the App Store name, which is free to change;
- the i18n `app.name` string;
- the store texts.

The bundle id (`com.niinova.plotwise`) can stay as it is, since users never see it.
